# Movie Data Pipeline

## Overview

This project implements a simple ETL (Extract, Transform, Load) pipeline using the MovieLens dataset and the OMDb API. It extracts movie and rating data from CSV files, cleans and transforms the data, enriches selected movie records with metadata from OMDb, and loads the results into a relational SQLite database.

## Objectives

- Extract movie and rating data from MovieLens CSV files.
- Clean movie titles and derive release years and decades.
- Normalize genres into separate relational tables.
- Validate and transform rating records.
- Enrich movie metadata using the OMDb API.
- Store the transformed data in SQLite.
- Answer analytical questions using SQL.

## Database Design

The SQLite database contains four tables:

- **movies:** Movie title, release year, decade, OMDb IMDb ID, director, plot, box office, and API enrichment status.
- **genres:** Unique genre names.
- **movie_genres:** Junction table representing the many-to-many relationship between movies and genres.
- **ratings:** User ratings and rating timestamps associated with movies.

Foreign keys maintain relationships between movies, genres, and ratings.

## ETL Process

### 1. Extract

The pipeline reads `movies.csv` and `ratings.csv` from the MovieLens dataset.

### 2. Transform

- Parses movie titles to derive clean titles and release years.
- Derives decade values from release years.
- Validates rating values and removes invalid or duplicate records.
- Splits genre values into normalized genre records and movie-genre relationships.

### 3. Enrich

The pipeline requests additional movie metadata from the OMDb API, including IMDb ID, director, plot, and box office information. API responses are cached to reduce repeated requests.

### 4. Load

The pipeline creates the database schema and loads movie, genre, movie-genre, and rating records into SQLite. Existing movie records are updated when the pipeline is rerun, and duplicate rating records are avoided.

## Setup

### Prerequisites

- Python 3.10 or later
- A valid OMDb API key

### Install dependencies

```bash
pip install -r requirements.txt
```

### Configure environment variables

Create a `.env` file in the project root:

```text
OMDB_API_KEY=your_api_key_here
DATABASE_URL=sqlite:///movies.db
```

Replace the placeholder with your own API key. Do not commit `.env` or expose your API key publicly.

### Run the pipeline

```bash
python etl.py
```

### Verify the database

```bash
python verify_database.py
```

### Run analytical queries

```bash
python run_queries.py
```

## SQL Analysis

The `queries.sql` file answers these questions:

1. Which movie has the highest average rating?
2. Which five genres have the highest average rating?
3. Which director has the most movies in the enriched dataset?
4. What is the average rating for each release year?

The highest-rated movie query also reports the number of ratings to provide context for the result.
